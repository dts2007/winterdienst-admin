# Winterdienst – Chef-Ansicht

Webseite für den Chef: Mitarbeiter, Aktivierungscodes, Einträge, Stunden und CSV-Export.
Anmeldung mit E-Mail und Passwort. Alle Daten liegen geschützt in Supabase. Ohne Admin-Anmeldung ist nichts sichtbar.

- `index.html`: Chef-Ansicht (erzeugt aus `admin/admin.src.html` im privaten Repo `winterdienst-app`)
- `Winterdienst.apk`: Android-App für die Mitarbeiter
